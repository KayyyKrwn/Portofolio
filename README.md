# Kia Kurniawan — Portfolio

Personal portfolio website: Data Analyst & Data Scientist.

- 🌐 Live: https://kayyykrwn.github.io/Portofolio/
- 🛠️ Static site (HTML/CSS/JS), no build step
- 🔒 Admin mode (🔒 button in header): set a password once, then add/edit/delete
  projects & certificates. Data is stored in the browser's localStorage —
  use Export/Import JSON to back up or move between devices.

## Preview locally

```bash
python3 -m http.server
# open http://localhost:8000
```
